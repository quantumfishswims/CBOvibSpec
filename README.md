# CBOvibSpec

CBOvibSpec is a python module for calculating linear spectra of vibrational polaritons
based on cavity Born-Oppenheimer perturbation theory (CBO-PT).  

### Literature:

- CBO-PT in JCTC:10.1021/acs.jctc.3c00708
- CBO-PT Linear Response (IR) in JPCL:10.1021/acs.jpclett.4c00105
